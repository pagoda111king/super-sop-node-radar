# Database Node Playbook Summary

Database capability belongs mainly under the Data Modeling node.

Use capability types:

- local state store
- analytical workspace
- vector memory
- product backend
- schema adapter

Do not say "best database node" without scope.

Good:

```text
DuckDB is a candidate for local analytical workspace over node artifacts.
```

Bad:

```text
DuckDB is the best database node.
```
